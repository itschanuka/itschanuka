- 💰 Deal workflows — reservations, trade-ins, finance
- 💳 Multi-entry payments & profit calculation
- 📊 Commission engine (automated by role)
- 📈 Report exports *(Excel, CSV, PDF, DOCX)*
- 🗂️ Append-only audit logs & soft delete recovery
- 💾 Backup & restore workflows

### 🔧 TradeTrack — Multi-Tenant SaaS

A full-stack SaaS prototype for **solo contractors** — replacing WhatsApp notes, scattered PDFs, and spreadsheets with one structured system.

**Stack:** Next.js · TypeScript · Node.js · Express · Supabase PostgreSQL · Tailwind CSS

**Core workflow:**
```
Client → Quote → Job → Invoice → Reminder → Payment
```

**Features:**
- 🏢 Multi-tenant SaaS architecture
- 🧾 Quote-to-job & job-to-invoice conversion
- 💸 Partial payment tracking
- 📅 Reminder rules & daily action dashboard
- 📁 Document folders & file management
- ⚙️ Business profile, onboarding & settings
- 📤 Report exports & subscription logic
